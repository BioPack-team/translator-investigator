## reasoner-api (TRAPI standard — reference)

For questions about **how a TRAPI API should behave** (intended semantics: `knowledge_level` /
`agent_type`, provenance / retrieval sources, binding structure, qualifier rules, etc.), consult the
**ReasonerAPI** reference in `repos/ReasonerAPI/` — especially
`ImplementationGuidance/Specifications/` and `docs/reference.md`. **Guidance is per-branch by TRAPI
version** (`1.6` / `2.0` / …) — `git -C repos/ReasonerAPI checkout <version>` to match the
component's `trapi_version` before reading. It complements TOM (structure / schema); **ignore its
schema yaml — use TOM for that.**
